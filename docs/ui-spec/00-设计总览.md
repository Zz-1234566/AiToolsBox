## 一、产品定位

**AI Tools Box**（你的 AI 工具箱）：移动端聚合型工具应用，统一封装多类 AI 能力（文档 / 图片 / 音频 / 视频 / 开发 / 办公）。

**核心价值**：用户在一个 App 内完成多类 AI 任务，无需安装多个 AI 工具。

**用户特征**：
- 学生 / 职场人士 / 创作者
- 任务碎片化、操作单次性强（多数 1~3 步完成任务）
- 对加载速度、结果可用性、操作简洁度敏感

---

## 二、页面地图

应用共 8 个核心页面 + 多个衍生状态页面，按 Tab 组织 5 个一级入口：

| 一级 Tab | 页面 | 路径建议 | 用途 |
|---|---|---|---|
| 首页 | 首页 | `/home` | 入口聚合 + 个性化推荐 |
| 分类 | 分类页 | `/category` | 工具全量列表 + 分类筛选 |
| 工作流 | 工作流列表 | `/workflow` | 已编排的多步工具流 |
| 收藏 | 我的收藏 | `/favorites` | 收藏的工具 + 收藏的工作流 |
| 我的 | 个人中心 | `/me` | 用户信息 + 设置 |

**二级 / 详情页（无 Tab）**：
- 搜索页 `/search`
- 工具详情页 `/tool/:id`（含：未上传态、上传后态、处理中态、处理完成态）
- 工作流详情页 `/workflow/:id`

## 三、完整用户流程

### 3.1 找工具并使用（主流程）

```
首页
  → 点击搜索框 / 点击工具卡片
  → 搜索页 / 工具详情页
  → 上传素材（图片 / 文档 / 音频）
  → 选择参数（可选）
  → 点击「开始处理」
  → 处理中（Loading + 进度条）
  → 处理完成（展示结果 + 下载 / 二次处理）
```

### 3.2 使用工作流

```
工作流 Tab
  → 选中工作流
  → 工作流详情页
  → 按步骤依次执行（步骤 1 → 2 → 3 ...）
  → 中间产物可在下一步复用
  → 最终产物统一展示
```

### 3.3 收藏 / 复用

```
任意工具详情页 / 搜索结果
  → 点击 ☆ 图标
  → 收藏 Tab 查看
  → 二次进入直接续用（不重新加载）
```

### 3.4 个人设置
```
我的 Tab
  → 账号设置 / 通知 / 主题（深色模式）/ 关于
```

## 五、设计原则（必须遵守）

1. **内容优先**：工具图标 + 名称 + 一句话描述 > 装饰元素
2. **单一任务**：每屏只解决 1 个核心任务
3. **状态显性**：Loading / Empty / Disabled / Success / Error 必须有明确视觉反馈
4. **可逆可中断**：长任务支持「取消处理」；危险操作支持撤销 Toast
5. **统一规范**：相同功能的视觉/交互在所有页面保持一致
6. **离线友好**：弱网 / 断网有明确提示，不静默失败
7. **可达性**：颜色不是唯一信息载体（图标 + 文字配合）
