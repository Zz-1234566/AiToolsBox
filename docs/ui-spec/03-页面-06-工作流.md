## 一、工作流列表

### 1.1 页面目标

让用户**浏览**已编排好的多步 AI 工作流,并直接运行。

### 1.2 页面结构

```
┌────────────────────────────────┐
│ StatusBar
├────────────────────────────────┤
│ TopBar
│   "工作流"  左对齐 18/600
│                       [+ 创建工作流](蓝色按钮)
├────────────────────────────────┤
│ 卡片列表（单列）
│   "商品图生成视频工作流"
│   "从商品图到宣传视频，一键完成"
│   👁 12.6万次           ☆ 空心 24×24
│   节点缩略（5 步，竖向）
│     [📷]  上传商品图
│      │    支持 JPG / PNG / WEBP
│      │
│     [🖼]  图片去背景
│      │    自动移除图片背景
│      │
│     [✨]  图片增强
│      │    智能提升画质与色彩
│      │
│     [📊]  生成商品海报
│      │    一键生成营销海报
│      │
│     [🎞]  生成宣传视频
│           输出 1080P 宣传视频
│   [运行工作流] 主按钮（宽 100%）
└────────────────────────────────┘
```

### 1.3 各区块详细规范

#### TopBar

- 标题左对齐："工作流"
- 右侧："+ 创建工作流" 蓝色按钮（高度 32、圆角 8、文字 13/500 主色）
  - 点击 → Modal"工作流创建中，敬请期待"或 `/workflow/new`

#### 工作流卡片

- 圆角 12、背景白、阴影 `--shadow-sm`
- 内边距 16
- 顶部：
  - 标题 16/600 主色
  - 右上角 ☆ 收藏按钮
- 一句话描述 13/400 次级
- 👁 次数 12/400 次级
- 节点缩略（**竖向**）：
  - 左侧轨：32×32 圆形渐变小方块（按工具类型配色） + 垂直连接线 2px 灰色
  - 右侧文本：节点名称 14/500 主色 + 副描述 12/400 次级
  - 单节点高度 ≥ 56，行间靠连接线自然分隔
  - 最后一项无线
- "运行工作流"主按钮 100% 宽

### 1.4 交互

| 元素 | 触发 | 跳转 |
|---|---|---|
| 工作流卡片 | 点击 | `/workflow/{id}` |
| ☆ | 点击 | 收藏 / 取消收藏 |
| 创建工作流 | 点击 | 暂未开放 Modal |
| 运行工作流 | 点击 | 进入工作流详情执行态 |

### 1.5 状态

- 默认：设计稿现状（1 条工作流）
- Loading：1 行骨架屏
- Empty："还没有可用工作流" + 提示"创建你的专属工作流，让创作更高效"
- 错误：全屏错误

## 二、工作流详情页

### 2.1 页面结构（执行态）

```
┌────────────────────────────────┐
│ StatusBar
├────────────────────────────────┤
│ TopBar
│   ←
│   "商品图生成视频工作流"
│                       ☆
├────────────────────────────────┤
│ 描述区
│   标题 + 描述 + 次数
├────────────────────────────────┤
│ 步骤进度（垂直）
│   步骤 1 上传商品图       [开始]
│   步骤 2 图片去背景       [等待步骤 1]
│   步骤 3 图片增强         [等待步骤 2]
│   步骤 4 生成商品海报     [等待步骤 3]
│   步骤 5 生成宣传视频     [等待步骤 4]
├────────────────────────────────┤
│ 底部按钮
│   [运行工作流] 或 [下一步]
└────────────────────────────────┘
```

### 2.2 步骤项

- 高度 56、内边距 16
- 左侧：40×40 渐变方块图标
- 中：步骤名称 16/500 + 状态文字 12/400 次级（"等待步骤 1" / "处理中..." / "已完成"）
- 右：状态图标 / 操作按钮
  - 待开始：灰色圆 + "开始" 文字按钮
  - 进行中：主色 Spinner + "处理中"
  - 已完成：主色 ✓ + "查看"
  - 失败：红色 ✗ + "重试"

### 2.3 状态流转

```
步骤 1 待开始
  ↓ 点击"开始"上传
步骤 1 进行中
  ↓ 自动完成
步骤 1 已完成
  ↓ 自动进入步骤 2
步骤 2 待开始
  ...
```

**用户可在任意步骤暂停 / 跳过（需 Modal 二次确认）**。

### 2.4 数据来源

- `/api/workflows` → 列表
- `/api/workflows/:id` → 详情（含步骤定义）
- `/api/workflows/:id/run` → 运行
- `/api/workflows/:id/step/{stepId}/run` → 执行单步

请求失败 → 该步骤失败态 + "重试"按钮。
