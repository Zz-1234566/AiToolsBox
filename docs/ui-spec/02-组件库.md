# 02 — 组件库（Component Spec）

> 所有页面只能使用本文定义的组件。设计稿中出现的视觉/交互必须能映射到某个组件。
> Token 引用见 `01-设计系统.md`。

---

## 一、Button（按钮）

### 1.1 规格

| 类型 | 高度 | 圆角 | 字号 | 用途 |
|---|---|---|---|---|
| 主按钮 Primary | 48 | 12 | 16 / 600 | 关键操作（开始处理、保存） |
| 次按钮 Secondary | 48 | 12 | 16 / 600 | 次要操作（取消） |
| 文字按钮 Text | 32 | 8 | 14 / 500 | 行内操作（清空、跳过） |
| 胶囊按钮 Pill | 32 | 9999 | 14 / 500 | Tab 切换、tag |
| 小型按钮 Mini | 32 | 8 | 13 / 500 | 行内（开通、编辑） |

### 1.2 状态

| 状态 | 视觉 | 说明 |
|---|---|---|
| 默认 | 背景主色 / 文字白色 | — |
| Hover | 背景 `--brand-primary-hover` | 仅触屏设备可省略 |
| Pressed | 透明度 0.85 | 全局统一（与 refactor 分支动画简化原则一致） |
| Disabled | 背景 `#E5E7EB`，文字 `#9CA3AF` | 不可点 |
| Loading | 主按钮内显示 Spinner + 文案变透明 | 文案保留 |
| Success | 主色 → 绿色 0.3s | 短操作完成后回弹 |

### 1.3 主按钮"开始处理"宽度

- 默认：宽 100%（左右 16px 内边距）
- 文字：`开始处理` / `运行工作流` / `取消收藏`（按上下文动态变化）

## 二、Input（输入框）

### 2.1 搜索框（首页、搜索页）

```
高度: 40
圆角: 9999（胶囊）
背景: --bg-page
左边: 12px 占位图标（搜索）
占位: "搜索你需要..." / "搜索 AI 工具"
右边: 12px 搜索 icon（搜索页）
```

### 2.2 表单输入

| Token | 值 |
|---|---|
| 高度 | 52 |
| 圆角 | 8 |
| 内边距 | 16 |
| 边框 | 1px `--border-default` |
| Focus 边框 | 1px `--brand-primary` + 0 0 0 3px `--brand-primary-light` |
| Error 边框 | 1px `--color-error` + 错误文案 `--color-error` 12px |

## 三、Tabs

### 3.1 顶部 Tab（分类页、工作流）

- 高度：44
- 横排 + 横向滚动（溢出可滑动）
- 激活态：文字主色 + 底部 3px 主色下划线（分割线颜色过渡）
- 未激活：文字次级
- 间距：`space-5`

### 3.2 中部 Tab（收藏页"工具 / 工作流"）

- 胶囊背景容器：高度 40，背景 `--bg-page`
- 单个 Tab：高度 32，激活态背景白色 + 阴影 `--shadow-sm`

---

## 五、TabBar（底部导航）

| 属性 | 值 |
|---|---|
| 高度 | 56（含安全区） |
| 背景 | `--bg-card` |
| 顶部边框 | `0.5px solid var(--border-light)` |
| 阴影 | `--shadow-bottom-nav` |

5 个 Tab：
1. 首页（house）
2. 分类（grid 2x2）
3. 工作流（list）
4. 收藏（heart）
5. 我的（user）

激活态：图标 + 文字主色；非激活：图标 + 文字 `--text-tertiary`。
激活态图标可填充（fill），非激活为线框（outline）。

## 六、Card（卡片）

### 6.1 工具卡片（首页热门工具）

```
宽度: (屏宽 - 16*2 - 12) / 2  ≈ 50% - 24px
高度: 自适应（≈ 100）
内边距: 12
圆角: 12
背景: 白
阴影: --shadow-sm（默认）/ --shadow-md（hover）
```

内容：
- 顶部 32x32 渐变方块图标
- 工具名称（16/600）
- 一句话说明（13/400 次级）
- 左下角：分类 tag（11/500 文字次级 + 浅背景）
- 右下角：☆ 图标

### 6.2 工具列表项（分类页、搜索结果）

```
高度: 72
布局: 左 icon 40x40 + 中(名称+描述) + 右(次数+❤)
分隔线: 0.5px --border-light
```

### 6.3 工作流卡片（工作流页）

```
宽度: 100%
高度: 自适应
圆角: 12
内边距: 16
背景: 白
```

内容：
- 标题 + 右上角 ☆ 收藏
- 一句话描述
- 12.6万 次
- 节点缩略（5 个圆形渐变小方块，纵向连线）

## 七、Step（步骤指示器，工具详情页）

- 横向 3 步：`1 上传图片 → 2 AI 处理 → 3 获取结果`

## 十、Toast / Message

- 顶部弹出，高度 48，背景黑色 80% 透明，圆角 8
- 出现 / 消失：0.2s slide-down / fade-out
- 时长：成功 2s，错误 3s
- 图标前缀：✓ 成功、✗ 失败、ℹ 信息

---

## 十一、Modal / ActionSheet

### 11.1 通用 Modal
- 居中弹出 + 蒙层 `--bg-mask`
- 内容宽度 ≤ 320px
- 圆角 `--radius-2xl`
- 进入动画：fade + scale 0.95 → 1（0.2s ease-out）

### 11.2 底部 ActionSheet
- 自底弹出 + 上方蒙层
- 顶部圆角 `--radius-2xl`
- 进入：slide-up 0.25s ease-out

---

## 十二、Empty / Status

### 12.1 Empty（收藏页"还没有收藏工具"）
- 图标 64px（盒子里带问号）
- 主文案"还没有收藏工具"
- 次文案"收藏常用工具，方便下次快速使用"

### 12.2 Loading
- 全屏：居中 Spinner + 文案"加载中..."
- 局部（卡片）：骨架屏 + 卡片占位

### 12.3 Error
- 全屏：图标 64px + 文案 + 重试按钮

## 十三、Avatar / Logo / Tag

### Avatar
默认 40×40 圆（9999px），图片加载失败时回退到 `默认头像/` 中的占位图（蓝底白字首字母）。

### Tag
高度 20，圆角 4，内边距 0 6px，背景 `--brand-primary-light` 或 `--bg-page`，文字 11/500。

## 18、Skeleton（骨架屏）

用于 Loading 状态下的占位：
- 卡片 / 列表项结构但内容替换为灰色色块（`--bg-disabled`，#F3F4F6）
- 可选脉冲动画（opacity 0.6 → 1，1.4s 循环）
- **慎用**：长任务改用进度条而非骨架屏
