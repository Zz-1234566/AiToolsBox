# 04 — 交互状态规范（State Spec）

> 适用于所有页面 / 组件
> 设计稿中已观察到的状态：默认、Loading、Empty、Error、Disabled、Success、Active

---

## 一、Loading（加载中）

### 4.1 全屏

- 居中 Spinner 24px + 文案"加载中..." 14/500 次级
- 背景 `--bg-page`
- 适用于首次进入页面

### 4.2 局部（骨架屏）

- 与目标内容结构 1:1
- 色块背景 `--bg-disabled`
- 圆角与目标元素一致
- 可选脉冲动画：opacity 0.6 → 1 → 0.6，1.4s 循环

### 4.3 列表 Loading

- 5 行骨架 + Spinner 底部居中
- "加载更多..." 12/400 次级

### 4.4 按钮 Loading

- 替换按钮文字为 Spinner + 半透明白色文案
- 按钮宽度不变（避免抖动）

### 4.5 进度条 Loading

- 用于长任务（AI 处理）
- 详见 `03-页面-08-工具使用中.md §3.4`

### 4.6 关键原则

- 单页面内**只允许一种 Loading 形态**（要么骨架要么 Spinner，不混用）
- Loading 期间禁用主按钮（防止重复提交）
- Loading 超过 5s 显示"还在加载..."或加进度提示

## 二、Empty（空态）

### 4.7 通用规则

| 元素 | 视觉 |
|---|---|
| 主图标 | 48-64px 主色或次级 |
| 主文案 | 14/500 主色 |
| 次文案 | 12/400 次级 |
| 行动按钮（可选） | 主按钮 |

### 4.8 各页 Empty 文案

| 页面 | 主文案 | 次文案 |
|---|---|---|
| 首页 最近使用 | 还没有使用记录 | 快去试试 AI 工具吧 |
| 收藏（工具） | 还没有收藏工具 | 收藏常用工具，方便下次快速使用 |
| 收藏（工作流） | 还没有收藏工作流 | 收藏好用工作流，一键运行工作流 |
| 搜索结果 | 未找到相关工具 | 试试其他关键词 |
| 工作流列表 | 还没有可用工作流 | 创建你的专属工作流，让创作更高效 |
| 分类列表 | 该分类下还没有工具 | 换个分类试试 |

### 4.9 可实现性

- Empty 不是 Loading：内容结构完全展示，只是没有数据
- Empty 不是 Error：没有红色提示色
- 提供行动入口：要么导航、要么主按钮（如"去逛逛"）

## 三、Error（错误）

### 4.10 错误展示层级

| 场景 | 展示形式 |
|---|---|
| 全页加载失败 | 全屏错误页 + 重试 |
| 局部区块失败 | 区块内错误（保留其他区块） |
| 操作失败 | Toast |
| 异步任务失败 | 失败态（详见对应页面） |
| 表单校验失败 | 输入框下方红字 + 红边框 |

### 4.11 全屏错误页

- 居中：
  - 图标 64px（红色或次级，告警 / 断线）
  - 主文案"加载失败" 16/600 主色
  - 次文案"网络异常或服务器繁忙" 13/400 次级
  - "重试" 主按钮

### 4.12 错误文案

| 场景 | 文案 |
|---|---|
| 网络断开 | 网络异常，请检查网络连接 |
| 服务器 500 | 服务器繁忙，请稍后重试 |
| 403 | 没有权限访问 |
| 404 | 内容不存在或已被删除 |
| 超时 | 请求超时，请重试 |
| 文件过大 | 文件过大，请上传小于 10MB 的图片 |
| 格式错误 | 暂不支持该格式 |

## 四、Disabled（禁用）

### 4.13 视觉

| 元素 | 禁用样式 |
|---|---|
| 按钮 | 背景 `#E5E7EB`、文字 `#9CA3AF` |
| 输入框 | 背景 `#F9FAFB`、文字次级 |
| 列表项 | 透明度 0.5 |
| 卡片 | 不响应点击、视觉不变 |

### 4.14 禁用原则

- 禁用元素保留占位（不消失）
- 禁用时**不响应 hover**
- 禁用 + tooltip 是好实践：解释为何禁用

---

## 五、Success（成功）

### 4.15 视觉

- 主色 `#10B981`
- ✓ 图标 + 文案
- 短操作：Toast 自动 2s 消失
- 任务完成：进入完成态（如工具完成态）

### 4.16 撤销 Toast

- 5 秒内可点击撤销
- 撤销 = 反向操作（典型：取消收藏可撤销 = 重新加入收藏）

---

## 六、Active / Pressed

### 4.17 全局 Active 视觉（与 refactor 分支原则一致）

- 主按钮：透明度 0.85
- 次按钮：背景 `--bg-page`
- 卡片：透明度 0.95
- **禁止**：缩放（已删除，见 refactor 提交记录）
- **禁止**：弹性曲线（已删除）

---

## 七、Focus

- 输入框 Focus：边框主色 + 0 0 0 3px `--brand-primary-light`
- 按钮 Focus：同上（PC 端可达性）
- 移动端：默认浏览器 focus 即可

---

## 八、过渡与反馈

### 4.19 操作反馈统一表

| 操作 | 即时反馈 | 完成反馈 |
|---|---|---|
| 点击按钮 | Pressed 0.85 | 跳页 / Toast |
| 上传文件 | Spinner | Toast / 替换预览 |
| 收藏 | ☆ 切换为实心 | Toast "已收藏"（可撤销） |
| 删除 | 立即消失 | Toast + 撤销 |
| 提交表单 | 按钮 Loading | 跳页 / Toast |
| 网络请求失败 | — | Toast 错误 |

---

## 九、键盘交互

- 移动端：键盘"搜索"键 = 触发搜索
- 平板 / 桌面：Enter = 提交，Esc = 关闭弹窗
- Tab：Tab 键切换焦点（PC 端）

---

## 十、可达性（A11y）

- 所有 icon 按钮带 `aria-label`
- 颜色不是唯一信息载体（图标 + 文字配合）
- 焦点环明显
- 错误信息不仅用颜色（红框 + 红字 + icon）
- 触控目标 ≥ 44×44

---

## 十一、用户操作结果反馈（关键流程）

### 进入功能 → 输入信息 → 提交 → Loading → 处理完成 → 查看结果 → 继续操作

```
✅ 首页
✅ 搜索
✅ 工具详情 - 上传
✅ 工具详情 - 处理中
✅ 工具详情 - 完成
✅ 收藏
✅ 取消收藏 + 撤销
✅ 工作流运行
✅ 用户登录 / 退出
```

每个流程都必须有：
1. **即时反馈**：操作发生立即视觉变化
2. **过程反馈**：Loading 状态可见
4. **结果反馈**：成功 / 失败明确
4. **异常恢复**：失败可重试、有撤销

---

## 十二、关键提示

- ❌ 禁止：用户操作后无任何反馈（"按钮按了没反应"）
- ❌ 禁止：错误状态只靠颜色（用户色盲看不见）
- ❌ 禁止：长任务无进度反馈（用户等不及刷新）
- ❌ 禁止：失败状态无法重试
