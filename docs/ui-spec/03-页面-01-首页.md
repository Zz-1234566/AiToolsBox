# 03 — 页面 01：首页

> 路径：`/home`
> 设计稿：`前端ui.png` 第一列第一屏
> 复用组件：TabBar、Tabs、Cards、Search Bar、Avatar、Tag、IconButton

---

## 一、页面目标

让用户**快速进入工具**或**快速找到想要的工具**，并形成"我经常用什么"的记忆。

## 三、各区块详细规范

### 3.1 TopBar

- 背景：`--bg-card`（白）
- 左侧 Logo + 标题：
  - "AiT" 24/700 主色 + "AI Tools Box" 13/400 主色（同一行，整体作为 Logo）
- 右侧：
  - 🔍 搜索图标按钮（IconButton），点击 → `/search`
  - 头像 32×32 圆，点击 → `/me`

### 3.2 Hero 插画区

- 背景：`linear-gradient(135deg, #EFF6FF 0%, #F5F3FF 100%)`（非常浅的蓝紫渐变）
- 内边距：24 / 24 / 32
- 右侧装饰：3D 立方体 + 星光 SVG（点缀，不抢视觉）
- 主标题："AI Tools Box" 28/700 主色
- 副标题："你的 AI 工具箱" 14/400 次级
- 搜索框（**视觉锚点，最显眼元素**）：
  - 高度 48、圆角 12、背景白、阴影 `--shadow-sm`
  - 占位文案"搜索你需要的 AI 工具" + 右侧放大镜图标按钮
  - 点击 → `/search`（携带焦点）

### 3.3 快捷分类

- 标题行：
  - 左："快捷分类" 16/600 主色
  - 右："全部分类 >" 13/400 主色（带 chevron），点击 → `/category`
- 内容：横向 7 项
  - 圆形图标方块 36×36（不同颜色背景，参考 § 1.3 工具配色）
  - 名称 11/500 主色，居中
  - 间距 16，**横滑溢出**（不要挤压）
  - "全部"激活态：背景 `--brand-primary-light`

**类目颜色映射**：
| 分类 | 背景 | icon |
|---|---|---|
| 全部 | `#EFF6FF` | 主色 grid 图标 |
| 文档 | `#FEE2E2` | 红 PDF |
| 图片 | `#E0E7FF` | 紫 图 |
| 音频 | `#FEF3C7` | 黄 mic |
| 视频 | `#FCE7F3` | 粉 play |
| 开发 | `#D1FAE5` | 绿 code |
| 办公 | `#F3E8FF` | 紫 doc |

### 3.4 热门工具

- 标题行：
  - 左："热门工具" 16/600
  - 右："查看更多 >" 13/400 主色
- 内容：2 列网格，间距 12
- 卡片：参考 § 6.1（工具卡片）
- 数据展示：当前共 4 个常用工具（与设计稿一致）

### 3.5 最近使用

- 标题行：
  - 左："最近使用" 16/600
  - 右："更多 >" 13/400 主色
- 内容：纵向列表，每项 56 高度
- 单项：40×40 渐变图标 + 工具名称 16/500 + "1小时前" 12/400 次级
- 点击 → 工具详情页
- 空态："还没有使用记录" + 提示文案

## 五、状态

### 5.1 默认（设计稿现状）
见上。

### 5.2 加载中
- Hero 区、分类、热门工具三个区域分别独立显示骨架屏
- 最近使用：显示 3 行骨架

### 5.3 空态（首次使用）
- 热门工具区：仅显示 4 个系统推荐工具
- 最近使用：显示空态插图 + 提示

### 5.4 错误
- 全屏错误 + 重试按钮（"网络异常，点击重试"）

### 5.5 弱网
- 数据可缓存部分正常展示，仅 Loading 慢一点
- 不静默失败

## 六、响应式

| 设备 | 调整 |
|---|---|
| 手机（≤640） | 设计稿当前布局 |
| 平板（641~1024） | 2 列工具卡片 → 3 列；快捷分类横向居中；Hero 文案更大 |
| 桌面（≥1025） | 内容居中宽度 ≤ 480px；保持移动版式不变 |

## 七、可实现性提示（前端）

- Hero 插画区：SVG 装饰图，建议放到静态资源
- 渐变图标方块：CSS `linear-gradient` + 居中 SVG
- 2 列网格：CSS Grid `grid-template-columns: 1fr 1fr; gap: 12px`
- 快捷分类横滑：`overflow-x: auto; -webkit-overflow-scrolling: touch;`，**禁止**用 `display: none` 隐藏溢出项
- 骨架屏：与卡片结构 1:1，色块使用 `--bg-disabled`
- 头像 / 工具图标：图片懒加载 + 失败回退占位图（`默认头像/`）

---

## 八、数据来源

- `/api/tools/hot?limit=4` → 热门工具
- `/api/categories` → 快捷分类
- `/api/history/recent?limit=10` → 最近使用

请求失败时,所有区块**独立降级**(某个失败不影响其他区块显示)。
