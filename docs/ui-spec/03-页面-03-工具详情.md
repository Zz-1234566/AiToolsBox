## 八、可实现性提示

- 上传组件：H5 `<input type="file" accept="image/*">` + `FormData` 上传
- 大文件：客户端先压缩到 ≤10MB（canvas toBlob）
- 上传进度：监听 `XMLHttpRequest.upload.onprogress` 显示在进度条
- 返回拦截：`beforeRouteLeave` 检查 `hasUnsavedUpload`，弹 Modal 确认
- 步骤切换：用本地 state 而非路由，保证切换流畅

## 九、数据来源

- `/api/tools/:id` → 工具详情（名称、描述、配置项 schema）
- `/api/upload` → 文件上传（返回 fileId）
- `/api/tools/:id/run` → 提交处理（带 fileId + params）
- `/api/tools/:id/result/:taskId` → 轮询结果（处理中）或 SSE

请求失败 → Toast 错误并保留表单。
