# 03 — 页面 02：分类页

> 路径：`/category`
> 设计稿：`前端ui.png` 第一列第二屏
> 复用组件：TabBar、Tabs、List Item、Search IconButton

---

## 一、页面目标

让用户通过**类目筛选**浏览全部 AI 工具,并直接进入工具详情。

---

## 二、页面结构（自上而下）

```
┌────────────────────────────────┐
│ StatusBar
├────────────────────────────────┤
│ TopBar                          │ ← 高度 56
│   "AI 工具"  居中 18/600        │
│                       🔍  ← 搜索按钮 32
├────────────────────────────────┤
│ 分类 Tab                         │ ← 高度 44
│ 全部（胶囊主色激活）/ 文档 / 图片 / 音频 / 视频 / 开发 / 办公

├────────────────────────────────┤

│   [左 40x40 渐变方块]

```

## 三、各区块详细规范

### 3.1 TopBar

- 标题居中："AI 工具" 18/600
- 左侧无返回（Tab 进入）
- 右侧：🔍 搜索按钮（32×32 图标按钮），点击 → `/search`

### 3.2 分类 Tab

- 高度 44
- 横排 + 横向滚动（溢出可滑）
- 单个 Tab：
  - 内边距：8 12
  - 文字 14/500
  - 激活态：背景主色 + 文字白（胶囊样式）
  - 未激活：文字次级，背景透明
- 默认激活"全部"
- Tab 间距：8
- 容器：白底，`padding: 0 16`，**底部 1px 分隔线**

### 3.3 工具列表

- 单列布局
- 间距：0（ListItem 间靠分隔线区分）
- 单条 / 共条：

| 属性 | 值 |
|---|---|
| 高度 | 72 |
| 内边距 | 16 |
| 图标 | 40×40 渐变方块（颜色按类型映射） |
| 标题 | 16/500 主色 |
| 描述 | 13/400 次级 |
| 次数 | 12/400 次级 + 👁 图标（左侧） |
| ❤ | 12/400 次级 + 心形图标（左侧） |

数据展示：

```
PDF 总结       快捷提取 PDF 核心内容       👁 12.3万次   ❤ 2.6万
图片去背景    一键移除图片背景             👁 10.8万次  ❤ 2.1万
OCR 识别      从图片中提取文字             👁 8.6万次    ❤ 1.8万
JSON 格式化   快速格式化和校验 JSON       👁 6.3万次    ❤ 1.4万
视频转文字    提取视频中的语音文字         👁 4.8万次    ❤ 1.2万
音频降噪      去除音频中的噪音             👁 3.8万次    ❤ 0.9万
代码生成      根据需求生成代码             👁 3.2万次    ❤ 0.8万
```

分隔线：最后一项**无**，其余 `0.5px solid var(--border-light)`。

|---|---|---|

## 五、状态

### 5.1 默认
设计稿现状。

### 5.2 Loading
- 列表渲染：7 行骨架屏
- 高度、宽度与 ListItem 一致
- 色块使用 `--bg-disabled`

### 5.3 空态
- 整个列表区显示空态插图（48px）+ "该分类下还没有工具" + "换个分类试试" 提示

### 5.4 错误
- 全屏错误（与首页一致）

### 5.5 下拉刷新
- 顶部下拉，松手后刷新整个列表
- 加载指示器：Spinner + "刷新中..."

## 六、响应式

| 手机 | 当前布局 |
| 平板 | 单列 → 双列（卡片样式切换），每个卡片显示工具列表项的全部内容 |
| 桌面 | 居中宽度 ≤ 480px，保持移动版式 |

---

## 八、数据来源

- `/api/categories` → Tab
- `/api/tools?category={id}&page=1` → 工具列表（分页）

请求失败 → 全屏错误。空数据 → 空态。

---

## 九、可实现性提示

- Tab 横滑：`overflow-x: auto`，不要 `display: none` 隐藏溢出项
- 切换 Tab 用 Vue/React 路由 query + 缓存列表
- 列表渲染：virtual list（>30 项时），避免一次渲染大量 DOM
- 次数格式化：`120000 → 12.0万`、`12000 → 1.2万`（用千分位 / 万 单位）
