# 03 — 页面 04：搜索页

> 路径：`/search`
> 设计稿：`前端ui.png` 第一行第四屏
> 复用组件：TopBar、SearchBar、Tag、ListItem

---

## 一、页面目标

让用户**快速检索工具**,并通过"热门搜索"和"搜索结果"两条路径触达目标。

---

## 二、页面结构（自上而下）

```
┌────────────────────────────────┐
│ StatusBar
├────────────────────────────────┤
│ TopBar
│   ← (返回)
│   [搜索框 🔍 "搜索 AI 工具"]      ← 自动 focus
│                              × (清空按钮, 仅输入有值时显示)
├────────────────────────────────┤
│ 热门搜索                         │ ← 默认显示, 输入后消失
│   标题："热门搜索"
│   Tag 流（横向换行）：
│     [PDF 总结] [图片去背景] [OCR] [视频生成] [JSON 格式化] [音频降噪]
├────────────────────────────────┤
│ 搜索结果                         │ ← 输入 ≥1 字符后显示
│   标题："搜索结果"
│   列表项：同分类页 ListItem
│   (与分类页布局一致)
└────────────────────────────────┘
```

---

## 三、各区块详细规范

### 3.1 TopBar（搜索框吸顶）

- 高度 56
- 左侧：← 返回按钮（IconButton 32×32）
- 搜索框（占满剩余空间）：
  - 高度 40、圆角 9999
  - 背景 `--bg-page`
  - 左：🔍 16px icon + 占位"搜索 AI 工具"
  - 右：× 清空按钮（**仅输入非空时显示**），点击 → 清空输入、清空结果、回到默认态
- 输入时自动 focus，键盘自动弹起

### 3.2 热门搜索

- 内边距：16
- 标题："热门搜索" 16/600 主色
- Tag 行：
  - 高度 32、圆角 9999
  - 内边距：0 12
  - 背景 `--bg-page`，文字 13/500 主色
  - 间距：8 / 8（横向、纵向）
  - **横排 + 自动换行**（不要横滑）
- 内容（按设计稿）：
  - PDF 总结、图片去背景、OCR、视频生成、JSON 格式化、音频降噪
- 点击 Tag → 填到输入框并触发搜索

### 3.3 搜索结果

- 标题："搜索结果" 16/600
- 列表项与分类页完全一致（参考 `03-页面-02-分类页.md §3.3`）
- 关键词高亮：
  - 工具名称 / 描述中匹配关键词的文字 → 文字主色加粗
  - 不匹配 → 默认文字次级

## 四、交互与跳转

| 元素 | 触发 | 跳转 |
|---|---|---|
| ← | 点击 | 返回 |
| × 清空 | 点击 | 清空输入 + 回到默认 |
| 热门 Tag | 点击 | 填入输入 + 搜索 |
| 结果项 | 点击 | `/tool/{id}` |

**键盘交互**：
- 移动端键盘"搜索"键 = 触发搜索
- 防抖：输入 300ms 后才请求 `/api/search`
- 取消请求：输入继续变化时取消上一次请求

---

## 五、状态

### 5.1 默认（设计稿现状）
热门搜索显示，搜索结果不显示。

### 5.2 搜索中
- 输入框右下角显示 Spinner 16px
- 结果列表显示骨架屏

### 5.3 有结果
- 显示搜索结果列表
- 关键词高亮

### 5.4 无结果
- 列表区显示空态：
  - 48px 搜索图标（次级）
  - "未找到相关工具" 14/500
  - "试试其他关键词" 12/400 次级
- 热门搜索仍保留（用户可继续点）

### 5.5 搜索失败
- 输入框下方红字错误"搜索失败，请重试"
- 保留输入内容

## 八、可实现性提示

- 输入防抖：用 `lodash.debounce` 或自定义 hook（300ms）
- 搜索请求取消：`AbortController` 取消上一次未完成请求
- 关键词高亮：用正则匹配后拆分为 React/Vue 渲染节点（避免 XSS）
- 键盘弹出：iOS Safari 16+ / Android Chrome 都需要 `scrollIntoView` 防遮挡

---

## 十、数据来源

- `/api/search?q={query}&limit=20` → 搜索结果
- `/api/search/hot` → 热门搜索 Tag 列表（首次进入获取，可缓存 24h）
