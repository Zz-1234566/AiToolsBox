# 01 — 设计系统（Design Tokens）

> 所有页面 / 组件必须使用本文件定义的 token，禁止页面级硬编码。

---

## 一、色彩系统

### 1.1 品牌色

| Token | 颜色 | 用途 |
|---|---|---|
| `--brand-primary` | `#3B82F6` | 主按钮、链接、激活状态、强调色 |
| `--brand-primary-hover` | `#2563EB` | 主按钮 hover |
| `--brand-primary-pressed` | `#1D4ED8` | 主按钮 active |
| `--brand-primary-light` | `#EFF6FF` | 选中背景、tag 浅背景 |
| `--brand-secondary` | `#6366F1` | 渐变副色、辅助强调 |

**主渐变**（首页插画、关键 Banner）：
```
background: linear-gradient(135deg, #3B82F6 0%, #6366F1 100%);
```

### 1.2 功能色（按状态区分）

| Token | 颜色 | 用途 |
|---|---|---|
| `--color-success` | `#10B981` | 成功状态、完成提示 |
| `--color-success-light` | `#D1FAE5` | 成功背景 |
| `--color-warning` | `#F59E0B` | 警告、积分不足提示 |
| `--color-warning-light` | `#FEF3C7` | 警告背景 |
| `--color-error` | `#EF4444` | 错误、失败、删除 |
| `--color-error-light` | `#FEE2E2` | 错误背景 |
| `--color-info` | `#3B82F6` | 信息提示 |

### 1.3 中性色（文字 / 背景 / 边框）

| Token | 颜色 | 用途 |
|---|---|---|
| `--text-primary` | `#111827` | 主标题、正文 |
| `--text-secondary` | `#4B5563` | 次级文本、描述 |
| `--text-tertiary` | `#9CA3AF` | 辅助、占位 |
| `--text-disabled` | `#D1D5DB` | 禁用文字 |
| `--text-on-brand` | `#FFFFFF` | 品牌色上的文字 |

| Token | 颜色 | 用途 |
|---|---|---|
| `--bg-page` | `#F9FAFB` | 页面背景 |
| `--bg-card` | `#FFFFFF` | 卡片背景 |
| `--bg-mask` | `rgba(0,0,0,0.5)` | 弹窗蒙层 |
| `--bg-disabled` | `#F3F4F6` | 禁用背景 |

| Token | 颜色 | 用途 |
|---|---|---|
| `--border-light` | `#F3F4F6` | 分隔线 |
| `--border-default` | `#E5E7EB` | 卡片描边 |
| `--border-strong` | `#D1D5DB` | 输入框描边 |

### 1.4 深色模式

通过 `html[data-theme="dark"]` 覆盖：

```
--bg-page:       #0B0F19
--bg-card:       #111827
--text-primary:  #F9FAFB
--text-secondary:#D1D5DB
--text-tertiary: #9CA3AF
--border-default:#1F2937
--brand-primary: #60A5FA   /* 略亮，提升对比度 */
```

| Token | 尺寸 | 典型用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字间距、tag 内边距 |

| `--space-5` | 20px | 区块间距 |

## 四、圆角

| Token | 尺寸 | 用途 |
|---|---|---|
| `--radius-sm` | 4px | tag、小型 chip |
| `--radius-md` | 8px | 输入框、小按钮 |
| `--radius-xl` | 12px | 卡片、按钮 |
| `--radius-2xl` | 16px | 大卡片、底部弹窗 |
| `--radius-full` | 9999px | 胶囊按钮、头像 |

**对照设计稿**：
- 工具卡片 → 12px
- 输入框 → 8px
- 主按钮 → 12px
- 底部 Tab 激活背景 → 8px（胶囊）
- 头像 → 9999px
- 工具图标方块（搜索结果、详情页）→ 12px

## 七、图标

### 7.1 来源

- **首选**：项目内 `App图标/` 目录中的 SVG（按工具类型分类）
- **次选**：自建 SVG iconfont（24px 网格，2px 描边，圆角端点）

### 7.2 尺寸

| Token | 尺寸 | 用途 |
|---|---|---|
| `--icon-xs` | 12px | tag 内、caption 配图 |
| `--icon-sm` | 16px | 列表前缀、数据强调前缀 |
| `--icon-md` | 20px | 输入框前缀、按钮内 |
| `--icon-lg` | 24px | 工具图标方块、TabBar |
| `--icon-xl` | 32px | 工具大图标（详情页头） |
| `--icon-2xl` | 48px | 空状态主图标 |

### 7.3 工具图标配色规则（关键）

工具卡片 / 详情页 / 搜索结果中的图标都使用 **渐变方块底**：

| 工具类型 | 渐变 | icon 颜色 |
|---|---|---|
| 文档类（PDF 总结） | `#FCA5A5 → #EF4444` | `#FFFFFF` |
| 图片类（图片去背景） | `#C7D2FE → #6366F1` | `#FFFFFF` |
| 开发类（JSON 格式化） | `#6EE7B7 → #10B981` | `#FFFFFF` |
| 音频类（音频降噪） | `#FCD34D → #F59E0B` | `#FFFFFF` |
| 视频类（视频生成） | `#F9A8D4 → #EC4899` | `#FFFFFF` |
| OCR 类 | `#93C5FD → #3B82F6` | `#FFFFFF` |
| 文字类（视频转文字） | `#A78BFA → #8B5CF6` | `#FFFFFF` |
| 代码类（代码生成） | `#5EEAD4 → #14B8A6` | `#FFFFFF` |

> 设计稿中已观察到：PDF 总结 = 红、OCR = 蓝、JSON = 紫、音视频 = 黄/粉，**严格按此延续**。

## 九、断点

| Token | 宽度 | 用途 |
|---|---|---|
| `--bp-mobile` | 0 ~ 640px | 手机（主战场） |
| `--bp-tablet` | 641 ~ 1024px | 平板 |
| `--bp-desktop` | ≥ 1025px | 桌面 |

> 应用本质是移动端，平板 / 桌面采用「自适应放大 + 多列布局」策略。详见 `05-响应式设计.md`。
