## 三、各区块详细规范

### 3.1 Hero 头部

- 背景：`linear-gradient(135deg, #EFF6FF 0%, #F5F3FF 100%)`
- 内边距：20 / 16 / 60（底部预留会员卡空间）
- 头像 48×48 圆（失败回退 `默认头像/`）
- 用户名 18/600 主色
- 会员信息：会员有效期 12/400 次级 + 高频会员 tag（11/500 文字 `rgba(255,255,255,0.9)` + 主色背景）

### 3.2 会员特权卡片

- 位置：相对 Hero 向下偏移 32px（**与 Hero 重叠**，类似 iOS 大标题风格）
- 圆角 12、背景深色 `#1F2937`、内边距 16
- 文字白色
- 标题 16/600 + 描述 13/400 次级（白色 80% 透明）
- "立即开通" 蓝色胶囊按钮（高度 32、文字 13/500 主色）— **注意**按钮文字在打卡视图上是主色文字白色背景
- 左右两段：左文字、右按钮

### 3.3 数据统计

- 单行 4 项（**注意**：只有"使用记录"有 chevron，其他是数字）
- 容器：白底、圆角 12、内边距 16 / 0
- 单项：
  - 高度 64、内边距 0 8
  - icon 24×24 + 文字 13/400 次级 + 数字 18/600 主色
  - **仅"使用记录"项右 chevron**

### 3.4 列表

- 通用 ListItem（参考 `02-组件库 §15`）
- 单项：
  - 高度 56、内边距 16
  - icon 24 + 文字 16/500
  - 右 chevron（Switch 项无 chevron）
- 顺序：账号设置 / 通知 / 深色模式 / 关于

### 3.5 深色模式 Switch

- 关闭：默认浅色
- 打开：全局切换到深色（设置 `html[data-theme="dark"]`）
- 切换过程 0.2s ease-out

## 八、可实现性提示

- 主题切换：localStorage 持久化 + 监听系统 `prefers-color-scheme`
- 数据统计请求失败 → 显示"--"
- 头像加载失败 → `onerror` 回退占位图
- VIP 卡：右上角"开通"按钮可能是阴影按钮（白底主色字）

---

## 九、数据来源

- `GET /api/me` → 用户信息 + VIP 状态 + 统计数据
- `PUT /api/me/preferences` → 深色模式设置
- `POST /api/auth/logout` → 退出
