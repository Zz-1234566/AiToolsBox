# 05 — 响应式设计（Responsive Spec）

> 设计稿是 375×812 (iPhone 11 Pro) 移动端尺寸。
> 平板 / 桌面采用"内容居中 + 限制最大宽度"策略，避免大屏上的稀疏布局。

---

## 一、断点

| Token | 宽度范围 | 设备 |
|---|---|---|
| `--bp-mobile` | 0 ~ 640px | 手机（主战场） |
| `--bp-tablet` | 641 ~ 1024px | 平板 |
| `--bp-desktop` | ≥ 1025px | 桌面 |

CSS 写法：

```css
/* 默认移动端 */
.container { padding: 0 16px; }

/* 平板 */
@media (min-width: 641px) {
  .container { padding: 0 24px; max-width: 720px; margin: 0 auto; }
}

/* 桌面 */
@media (min-width: 1025px) {
  .container { padding: 0 32px; max-width: 480px; margin: 0 auto; }
}
```

## 三、栅格系统

### 3.1 移动端

- 页面左右内边距：16px
- 列数：2 / 6 / 12（按需）
- 间距：12 / 16

### 3.2 平板

- 页面左右内边距：24px
- 列数：6 / 12
- 间距：16

### 3.3 桌面

- 页面最大宽度：480px（任务型）/ 720px（列表型）
- 内容居中
- 列数：12

## 四、底部 TabBar

| 设备 | 行为 |
|---|---|
| 手机 | 5 项横排，高度 56 |
| 平板 / 桌面 | 5 项横排，宽度限制在 480px 居中（避免太长） |

> 桌面端**不**改成侧边栏，避免破坏移动端用户的肌肉记忆。

## 五、字号响应式

| Token | 手机 | 平板 | 桌面 |
|---|---|---|---|
| `--text-display` | 24 | 28 | 32 |
| `--text-h1` | 20 | 22 | 24 |
| `--text-h2` | 18 | 20 | 22 |
| `--text-body` | 14 | 15 | 16 |
| `--text-caption` | 12 | 13 | 14 |

> **保守策略**：移动端字号已足够大，平板 / 桌面**只轻微放大**，避免破坏设计稿。

---

## 六、图片 / 媒体

- 图片必须 `max-width: 100%` 防止溢出
- 头像用 `aspect-ratio: 1` 保证圆
- 大图加载：`loading="lazy"` + `decoding="async"`
- 高分屏：SVG 优先，PNG 提供 2x / 3x

---

## 七、横屏处理

移动端横屏（极少使用）：
- 详情页：图片预览区拉宽，左右分栏（原图 + 处理中状态）
- 列表页：维持单列（横屏列表体验差）
- 不专门优化横屏，保证不破版即可

---

## 八、可实现性

- CSS：`@media (min-width: ...)` 优于 JS 监听 `resize`
- 移动端调试：Chrome DevTools 设备模式 + 真机（iOS Safari、Android Chrome）
- viewport meta：`<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">`
- 单位用 `rem` 而不是 `px` 时设置 `html { font-size: 16px }`（移动端），平板 / 桌面按比例放大
