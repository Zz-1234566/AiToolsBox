# 07 — 前端实现要点（Engineering Notes）

> 面向前端工程师的实现注意事项。
> 设计稿只是理想状态，实际开发要考虑：DOM 性能、组件复用、第三方组件适配、极端数据、可访问性。

---

## 一、技术栈建议

> 本规范以设计稿为基准，不绑死技术栈，但给出推荐。

| 框架 | 推荐 |
|---|---|
| 移动端首选 | Vue 3 + Vant 4 / uni-app |
| React 阵营 | React 18 + Antd Mobile / Taro |
| 跨端 | uni-app / Taro（小程序） |

**核心原则**：
- 用成熟的 UI 组件库做底层（如 Vant），不要全部自研
- 自研只做差异化组件（如工具卡片、步骤指示器）

## 六、第三方组件适配

### 6.1 Vant 组件覆盖

| Vant 组件 | 覆盖点 |
|---|---|
| `van-search` | 改圆角 / 改占位 |
| `van-tabs` | 用胶囊样式覆盖（自定义激活态） |
| `van-tabbar` | 自定义图标 |
| `van-uploader` | 限制大小 / 格式 |
| `van-button` | 主按钮颜色 / 圆角 |
| `van-empty` | 自定义图片 + 文案 |
| `van-skeleton` | 自定义行数 / 颜色 |

### 6.2 跨端注意

- 小程序：用 `rpx`，Web 用 `rem`
- 视频上传：H5 用 `<input>`、小程序用 `wx.chooseMessageFile`
- 上传进度：小程序：H5 监听 `XMLHttpRequest.upload.onprogress`

## 七、数据动态变化处理

### 7.1 长文本

| 场景 | 处理 |
|---|---|
| 工具名称 | 单行省略 |
| 工具描述 | 2 行省略 |
| 错误信息 | 完整展示（不省略） |
| 评论 / 说明 | 3 行 + 展开 |
| 工作流标题 | 单行省略 |

### 7.2 极端数据

| 场景 | 处理 |
|---|---|
| 0 条数据 | Empty 态 |
| 1 条数据 | 列表正常显示 |
| 1000 条 | 虚拟列表 / 滚动加载 |
| 次数超过 1000 万 | 显示"1000万+" |
| 头像图片 404 | 回退占位图 |
| 工具图标 404 | 回退通用图标 |
| 文件超大 | 客户端压缩 / 限制 10MB |
| 文件格式错误 | 错误 Toast |
| 接口超时 | Loading 超时提示 |
| 接口 500 | 全屏错误 + 重试 |

### 7.3 异常数据

| 场景 | 处理 |
|---|---|
| 后端返回 null | 默认值 |
| 字段缺失 | UI 隐藏该字段 |
| 类型错误 | 强类型校验 |
| 时间戳格式 | dayjs / date-fns 格式化 |
| HTML 注入风险 | 后端应已转义，前端不再处理 |

## 九、性能

### 9.1 首屏

- 关键 CSS inline
- 首屏图片懒加载
- 路由懒加载
- 字体子集化

### 9.2 列表

- > 30 条用虚拟列表
- 分页加载（每页 20 条）
- 图片懒加载

### 9.3 动画

- 仅 `transform` + `opacity`
- 避免同时动画 > 5 元素

### 9.4 包体积

- 按需引入（Vant 支持）
- Tree-shaking
- 图片 WebP / SVG

## 十、可访问性

- 所有 icon 按钮 `aria-label`
- 颜色不是唯一信息载体
- 焦点环明显
- 触控目标 ≥ 44×44
- 表单输入框 `<label>`
- 错误信息不仅用颜色

## 十二、与后端约定

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string / number | 资源 id |
| `name` | string | 名称 |
| `description` | string | 描述 |
| `category` | string | 分类 |
| `iconType` | enum | 工具类型（影响配色） |
| `usageCount` | number | 次数 |
| `favoriteCount` | number | 收藏数 |
| `isFavorited` | boolean | 当前用户是否收藏 |

API 响应格式统一：
```json
{
  "code": 0,
  "message": "ok",
  "data": { ... }
}
```

错误：`code !== 0`，message 是用户友好的中文文案。

## 十三、常见问题

### Q1：上传按钮和"开始处理"按钮太近，会不会误点？

A：上传完成前"开始处理"按钮禁用（透明度 0.5）。

### Q2：详情页返回会丢失已上传的图片吗？

A：保留到 store，离开时弹 Modal 二次确认。

### Q3：处理中页面返回会取消任务吗？

A：弹 Modal 确认；用户点确认才真正取消。

### Q4：搜索结果列表空时, 热门搜索还能用吗？

A：保留热门搜索，用户可继续点。

### Q5：VIP 卡在哪个页面出现？

A：仅在个人中心 Hero 区。

### Q6：收藏切换 ☆ 动画能否缩放？

A：**不能**。refactor 分支已删除按钮缩放与弹性，统一透明度反馈。
