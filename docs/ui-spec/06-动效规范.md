# 06 — 动效规范（Motion Spec）

> 原则：**快速、克制、有反馈**。动效服务于功能，不炫技。
> 与 `refactor/ui-animation-simplify` 分支原则一致：**去除缩放 / 弹性曲线，统一保留透明度反馈**。

---

## 一、时长

| Token | 时长 | 用途 |
|---|---|---|
| `--motion-instant` | 100ms | 按下反馈、收藏切换 |
| `--motion-fast` | 200ms | Toast、Switch、Tag 切换 |
| `--motion-default` | 250ms | Modal、ActionSheet、页面 push |
| `--motion-slow` | 400ms | 大区块出现（如 Loading 切换为内容） |

> 移动端优先**短时长**，**不超过 400ms**（人感知阈值）。

---

## 二、缓动函数

| Token | 值 | 用途 |
|---|---|---|
| `--ease-out` | `cubic-bezier(0.0, 0.0, 0.2, 1)` | 出现、展开、Toast |
| `--ease-in` | `cubic-bezier(0.4, 0.0, 1, 1)` | 消失、收起 |
| `--ease-in-out` | `cubic-bezier(0.4, 0.0, 0.2, 1)` | 状态切换 |
| `--ease-linear` | `linear` | Spinner 旋转、进度条 |

> **禁止使用**：自定义 cubic-bezier 弹性（已被 refactor 分支删除）。

---

## 三、按交互类型

### 3.1 按钮按下

- 视觉：透明度 0.85
- 时长：100ms
- 缓动：`--ease-in-out`
- 无位移、无缩放

### 3.2 页面切换

- 视觉：新页面从右滑入 + 旧页面淡出（iOS 风格）
- 时长：250ms
- 缓动：`--ease-out`
- 反向操作：从左滑回

### 3.3 Modal / ActionSheet

- **Modal**：
  - 蒙层：fade 200ms
  - 内容：scale 0.95 → 1 + fade 200ms（`--ease-out`）
- **ActionSheet**：
  - 蒙层：fade 200ms
  - 内容：从底滑入 250ms（`--ease-out`）

### 3.4 Toast

- 出现：从顶部下滑 + fade 200ms
- 消失：fade 100ms
- 停留 2s（成功）/ 3s（错误）

### 3.5 Switch

- 圆点滑动：200ms `--ease-in-out`
- 轨道颜色：100ms `--ease-in-out`

### 3.6 收藏切换（☆）

- 视觉：透明度 1 → 0.5 → 1（200ms）
- **无缩放**、**无旋转**、**无弹性**
- 简单可逆

### 3.7 上传区拖拽反馈

- 边框颜色过渡：100ms
- 整体 scale 1 → 1.005 → 1（100ms）— **仅上传区特殊**
- 其他场景**禁止** scale

### 3.8 加载 Spinner

- 旋转：`rotate(360deg)` 800ms `--ease-linear` 无限循环
- 大小：16 / 24 / 32（按场景）

### 3.9 进度条

- 进度变化：300ms `--ease-out`
- 进度从 0 → 100% 视觉平滑

### 3.10 骨架屏

- 脉冲：opacity 0.6 → 1 → 0.6，1.4s 循环
- 缓动：`--ease-in-out`

---

## 四、页面级转场

### 4.1 TabBar 切换

- 立即切换，无转场动画（点击响应要快）
- 激活态图标颜色 100ms 过渡

### 4.2 进入新页面

- 默认从右滑入（iOS 标准）
- 例外：弹窗类页面用 fade

### 4.3 返回

- 从左滑回
- 还原上一页状态

---

## 五、复杂动效（按价值判断）

| 动效 | 处理 | 价值 |
|---|---|---|
| 卡片上滑进入（列表） | 不做 | 增加复杂度无明显价值 |
| 数字滚动动画 | 不做 | 移动端没必要 |
| 页面 hero 装饰动画 | 可选 | 仅首次进入 |
| 长任务进度推进 | 进度条动画 | 用户期待 |
| 收藏成功 Toast | slide-down | 反馈 |
| 失败震动 | 可选（触屏） | 反馈 |

---

## 六、动效降级

- **reduce-motion**：用户系统设置 `prefers-reduced-motion: reduce` 时，**禁用所有非必要动效**（保留必要的反馈时长缩短到 100ms 内）。
- 长任务处理中：网络差时不阻塞 UI（用 background 任务）
- 低端机：减少同时动画数量

CSS：

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

---

## 七、性能约束

- 同时动画元素 ≤ 5 个
- 动画属性只用 `transform` + `opacity`（GPU 加速）
- 避免动画 `width` / `height` / `top` / `left`（触发 reflow）

---

## 九、可实现性

- 全部用 CSS transition / animation，不用 JS 计算
- Vue 用 `<transition>` 组件，React 用 `framer-motion` 或自实现
- 长任务动画：用 `requestAnimationFrame` 推进
- Spinner：SVG 旋转或 CSS `@keyframes`
