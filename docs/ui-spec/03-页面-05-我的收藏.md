# 03 — 页面 05：我的收藏

> 路径：`/favorites`
> 设计稿：`前端ui.png` 第二行第一屏
> 复用组件：TabBar、中部 Tab、ListItem、Empty

---

## 一、页面目标

让用户**快速复用**已收藏的工具和工作流。

---

## 二、页面结构（自上而下）

```
┌────────────────────────────────┐
│ StatusBar
├────────────────────────────────┤
│ TopBar
│   "我的收藏"  左对齐 18/600
├────────────────────────────────┤
│ 中部 Tab（胶囊容器）
│   [工具]（激活）/ [工作流]
├────────────────────────────────┤
│ 列表区
│   工具 Tab：ListItem（同分类页 + 右 ★ 实心）
│     · 图片去背景 / 一键移除图片背景 / [图片] tag
│     · PDF 总结
│     · OCR 识别
│     · JSON 格式化
│   工作流 Tab：工作流卡片列表（同工作流页）
├────────────────────────────────┤
│ Empty 状态（无收藏时）
│   📦 图标 64px
│   "还没有收藏工具"
│   "收藏常用工具，方便下次快速使用"
└────────────────────────────────┘
```

---

## 三、各区块详细规范

### 3.1 TopBar

- 标题左对齐："我的收藏" 18/600（**注意**：不是居中，是左对齐）
- 无右侧按钮

### 3.2 中部 Tab（参考 `02-组件库 §3.2`）

- 容器：高度 40、背景 `--bg-page`、圆角 9999、外边距 16
- 内边距 4
- 单个 Tab：
  - 高度 32、内边距 16 0
  - 文字 14/500
  - 激活：背景白 + 阴影 `--shadow-sm` + 文字主色
  - 未激活：文字次级
- 默认激活"工具"

### 3.3 工具列表

- 单列
- 单项：
  - 高度 72、内边距 16
  - 左：40×40 渐变图标
  - 中：标题 16/500 + 描述 13/400 次级
  - 右：★ 实心主色 24×24（**点击 → 取消收藏**）
  - 下方：分类 tag 11/500 + 浅背景（设计稿中"图片"等）
- 分隔线 0.5px，最后一项无

### 3.4 工作流 Tab 列表

参考 `03-页面-06-工作流.md §3.3` 的工作流卡片。

### 3.5 Empty 状态

- 整页内容区显示（Tab 仍可见）
- 居中：
  - 📦 图标 64px（次级）
  - "还没有收藏工具" 14/500 主色
  - "收藏常用工具，方便下次快速使用" 12/400 次级
- 顶部留白 80px

---

## 四、交互与跳转

| 元素 | 触发 | 跳转 |
|---|---|---|
| 工具项 | 点击 | `/tool/{id}` |
| 工作流项 | 点击 | `/workflow/{id}` |
| ★ 收藏 | 点击 | 取消收藏（Toast"已取消收藏"，**乐观更新**） |
| 中部 Tab | 点击 | 切换列表 |

---

## 五、状态

### 5.1 有收藏（设计稿现状）
工具 Tab 显示 4 条收藏。

### 5.2 Empty（无收藏）
显示空态插图。

### 5.3 取消收藏成功
- 乐观更新：立即从列表移除
- Toast"已取消收藏"
- 撤销按钮（5s 内可点击，撤销 = 重新加入列表）

### 5.4 Loading
- 列表显示骨架屏

### 5.5 错误
- 全屏错误 + 重试

---

## 七、响应式

| 设备 | 调整 |
|---|---|
| 手机 | 当前 |
| 平板 / 桌面 | 内容居中 ≤ 480px |

---

## 八、可实现性提示

- 取消收藏乐观更新：本地 state 立即移除 + 后台异步删除（失败回滚 + Toast 错误）
- Empty 与列表的切换：用 v-if 控制整块区域
- 中部 Tab 切换：用 state 缓存两个 Tab 的列表

---

## 九、数据来源

- `/api/favorites/tools?userId={id}` → 收藏工具
- `/api/favorites/workflows?userId={id}` → 收藏工作流
- `DELETE /api/favorites/{type}/{id}` → 取消收藏

请求失败 → 全屏错误。空数据 → Empty 态。
