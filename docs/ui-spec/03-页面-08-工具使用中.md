# 03 — 页面 08：工具使用中（处理中态）

> 路径：`/tool/:id/processing` 或 详情页内部切换
> 设计稿：`前端ui.png` 第二行第四屏（图片去背景 处理中 45%）
> 复用组件：TopBar、Progress、Button

> 该页是工具详情页的处理中态，单独成篇方便前端对照实现。

---

## 一、页面目标

让用户在 AI 处理期间**看到进度、知道还需要等多久、可以取消**。

## 三、各区块详细规范

### 3.1 TopBar

- ← 返回按钮：
  - 默认点击 → 弹 Modal"处理尚未完成，确定离开？"
  - 二次确认 → 取消任务并返回
- 标题居中：工具名
- ☆ 收藏：可点击（不影响处理）

### 3.2 图片预览

- 容器：白底 + 棋盘格背景（CSS `background-image` 平铺小灰格）
- 高度自适应（约 280）
- 图片：居中、最大宽高 = 容器 - 32 内边距
- 圆角 12

### 3.3 状态信息

- 主色 Spinner（24px、动画 `rotate 0.8s linear infinite`）
- 主文案"AI 正在处理中..." 14/500 主色
- 次文案"预计需要 10~30 秒，请耐心等待" 12/400 次级
- 垂直间距 8

### 3.4 进度条

- 高度 4、圆角 2
- 背景 `--border-light`
- 填充 `--brand-primary`
- 右侧文字"45%" 12/500 主色
- 动画：进度更新时 0.3s ease-out 平滑过渡

### 3.5 处理步骤列表

- 单列、3 项（参考设计稿）
- 单项高度 48、内边距 12
- 图标 24×24：
  - 已完成：✓ 主色背景 + 白字
  - 进行中：主色 Spinner
  - 未开始：灰色空圆
- 文字 14/500，状态不同颜色不同
- 容器：背景 `--bg-page`，圆角 12

### 3.6 取消按钮

- "取消处理" 次按钮 100% 宽
- 点击 → 调用 `/api/tools/:id/cancel` → 回到详情页（提示 Toast"已取消处理"）

## 五、状态流转

```
详情页未上传态
  ↓ 上传文件 + 点击"开始处理"
详情页已上传态
  ↓ 点击"开始处理"
处理中态（当前页）
  ↓ 完成 / 失败 / 取消
完成态（结果图 + 下载） / 失败态 / 详情页
```

**完成态**：
- 替换预览为结果图
- 步骤全部 ✓
- 按钮变为"下载结果" + "重新处理"

**失败态**：
- 步骤中失败的步骤标红 ✗
- 文案"处理失败，请重试" + "重新处理"按钮
- Toast 错误信息

**超时态**（>60s 无响应）：
- "处理时间较长，是否继续？" + "继续等待" / "取消处理"

## 八、可实现性提示

- 进度推送：
  - 方案 A：SSE / WebSocket 实时推送百分比
  - 方案 B：客户端轮询 `GET /api/tasks/:id/progress` 每 1s
- 取消：必须调用后端取消接口，不能仅前端停止轮询
- 离开拦截：`beforeunload` + 路由守卫二次确认
- 长任务保活：处理期间禁用屏幕休眠（可选，使用 `navigator.wakeLock`）
- 结果展示：使用 `<canvas>` 处理大图避免 OOM

---

## 九、数据来源

- `POST /api/tools/:id/run` body: `{ fileId, params }` → 返回 taskId
- `GET /api/tasks/:id/progress` → `{ progress, currentStep, status }`
- `GET /api/tasks/:id/result` → 完成时返回结果 URL
- `POST /api/tools/:id/cancel` body: `{ taskId }`

请求失败 → 失败态。超时 → 超时态。
