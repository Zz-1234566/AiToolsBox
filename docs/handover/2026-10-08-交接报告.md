## 五、已知技术陷阱（重要）

| 陷阱 | 说明 |
|---|---|
| **uni-h5 scroll-view 两层结构** | 外层 `overflow:visible` 高度跟随内容；**必须约束外层高度**，否则内容溢出盖住按钮且无法滚动 |
| **`input.multiple` 各端不同** | H5 原生 input / App `chooseMessageFile` |
| **`MultipartFile.transferTo`** | 内存版（工作流场景）不支持，会抛异常 |
| **`#ifdef H5`** | H5 测通 ≠ App 正常 |
| **mockup 假数据** | 已清理，但改 UI 时仍需警惕 |
