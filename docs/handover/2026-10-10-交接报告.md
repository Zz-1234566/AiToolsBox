## 3. 关键技术决策

### 3.1 Token 失效：时间戳方案（**不是集合**）
候选：A 黑名单 / **B 时间戳** / C 集合 / D 双 Token
**选 B**。理由：
- 改密仅写一次时间戳，O(1)
- 内存恒定（每用户一个 long）
- 存量 token 天然失效，不需要枚举

### 3.2 按钮 / 图标：SCSS mixin（**不是 Vue 组件**）
理由：多端（H5/小程序）零运行代价、渐进替换旧 `<el-button>`、编译期强制 flex 居中。
