# 生成演示文稿

## 流程

### 第 1 步：定页面结构
先给页面清单（每页一句话），不要直接开写：

```
1 封面：标题 + 副标题 + 日期
2 目录
3 背景与问题
4 方案概览
5 核心功能（3 个卡片）
6 技术架构（图）
7 数据对比（表）
8 总结
```

### 第 2 步：逐页生成内容
- 每页标题 ≤ 12 字，正文 ≤ 5 条，每条 ≤ 20 字
- 一页一个观点，不要堆字
- 需要图的地方留占位并说明画什么

### 第 3 步：渲染
调用 `pptx-write`，按模板套版式（标题页/内容页/图表页三种）。

### 第 4 步：交付
返回 pptx 文件卡，并说明共 N 页。

## 规范
- 不要大段文字，PPT 不是 Word
- 配色跟模板走，不自定义
