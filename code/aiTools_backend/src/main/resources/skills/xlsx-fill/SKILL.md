# 填写表格并导出

## 流程

### 第 1 步：先看表结构
调用 `xlsx-read` 返回：sheet 名、表头、行列数、前 5 行样例。
**不要把整表塞进上下文**，几万行会直接爆掉。

### 第 2 步：确认要改什么
| 用户说法 | 动作 |
|---|---|
| "填一下 XX 列" | 按行定位写入 |
| "加一列合计" | 新增列 + 公式 |
| "统计每个月总额" | 按字段分组聚合 |

### 第 3 步：执行
调用 `xlsx-write`，参数：
```json
{"file":"file_1","ops":[{"op":"fill","sheet":0,"header":"金额","row":1,"value":"380.00"}]}
```

### 第 4 步：校验后交付
- 写入后重新读取，确认单元格值正确
- 公式不能出现 `#REF!` `#DIV/0!` `#VALUE!`
- 保留原有格式：不新建工作表、不改列宽字号

## 规范
- 金额保留两位小数，负数用括号
- 日期写成文本 `2026-11-30`，不要变成数字序列号
- 改模板文件时遵循模板已有格式，不要强加新样式
